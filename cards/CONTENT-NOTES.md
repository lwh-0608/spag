## 4. 取舍与改写

- **C2 标题压缩**：CARD-SPEC 首页写作「付款之前，把「能不能生产」变成事实」；为满足 §1 标题 ≤16 字，data.json 用「付款前，把「能不能生产」变成事实」（16 字符含标点、13 汉字），语义不变，并在模板首个逗号处断成两行。
- **三个问题**压缩为副题「主体是否真实、能否生产、风险在哪」，与事实表「是否真实存在 / 是否真的具备生产能力 / 风险在哪里」一致。
- **五条承诺**在 C5 三点内全部保留，**七步交付**在 C3 三点内全部保留；均为压缩表述，未改变事实。
- **C4 英文标题**改为 "Subscription deliverables, no added headcount."（46 字符，两行），避免与要点 03 及模板默认 quote 三处重复 "no added headcount"；同时用 `quote_cn` / `quote_en` 覆盖模板默认 quote，改用公司简介的固定成本论点（「增设岗位是固定成本，业务量不是。」/ "Hiring is a fixed cost. Volume is not."）。其余卡使用 `layouts.py` 内置默认 quote（均取自事实表 / 服务说明口径）。
- **未写**：客户名称、可识别案例、从业年限、认证 / 保证 / 绝对化用语（最、第一、唯一、领先等）、行业估算 73%、20–100 倍；「认证 / 担保 / guarantee」只以否定形式出现在五条承诺中（照事实表原文）。英文为美式拼写与标点（serial comma）。
- **员工卡边界**：C8 的「15 分钟 / 三样信息」、C7 的「广东及周边省份」来自 B2/B3 个人资料，属个人职责表述，发布前须由本人确认；所有员工卡均未写年限与履历。
