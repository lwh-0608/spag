- 带 `[方括号]` 的内容是占位符，须由本人填写、确认后才能发布。
- 未标注价格的材料不报价；客户询价一律按第〇节事实表的报价口径回答。

How to read and copy:

- In Markdown each box is a code block; in Word and PDF each box is a light gray panel. Copy only the text inside; never copy the frame, the item number or the platform note.
- The Chinese and English versions carry the same facts and a native tone in each language; they are not literal translations. Publish the version that fits the audience; do not mix them.
- Prices and turnaround follow the fact sheet in section 0. If any item changes, update every asset.
- Anything in `[brackets]` is a placeholder; fill it in and confirm it before publishing.
- Assets without a stated price are not quoting tools. Answer every pricing question from the fact sheet in section 0.
